# SplitSmart AI

## Project Overview

SplitSmart AI is a modern expense-sharing web application that helps friends, roommates, and groups manage shared expenses.

The application should allow users to create groups, add expenses, split bills equally or custom, and track who owes whom through a clean and modern dashboard.
