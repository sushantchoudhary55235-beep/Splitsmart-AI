# SplitSmart

Design a modern, premium-quality responsive web application UI for an AI-powered expense sharing platform called "SplitSmart AI".

The design should feel cleaner and more premium than Splitwise, CRED, Notion, and Linear.

Use modern glassmorphism with subtle gradients, rounded corners, soft shadows, beautiful spacing, smooth animations, and a professional SaaS look.

Theme:

- Primary Color: Emerald Green (#10B981)

- Secondary: Blue (#3B82F6)

- Background: White with subtle gray gradients

- Accent: Purple

- Font: Inter

- Minimalistic design

- Mobile-first and fully responsive

Generate clean React + Tailwind CSS code using shadcn/ui components.
